# Monitoring, observability and GitOps

Metrics are numeric time series used for trends and alerts; logs are timestamped event records; traces connect a request across services. Together they help explain system behavior. Kubernetes monitoring commonly collects node, workload, and application metrics plus container logs; tracing adds request paths. Prometheus scrapes metrics and evaluates alert rules; Grafana visualizes configured data sources. This repo includes a running local Prometheus and Grafana Compose stack; the Session 20 README links live metrics and dashboard evidence.

GitOps treats version-controlled desired state as the source of truth. An in-cluster controller continuously compares live resources with Git and reconciles drift. The earlier Session 20 `session20-app` demonstration reached Synced/Healthy; see the evidence linked from this directory's README. The final project's `homework-api-local` Application also reached Synced/Healthy against this repository's Helm chart in Minikube. Its local image override and evidence are documented in `../final-devops-project/README.md`.
